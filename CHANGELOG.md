# Cambios

## Sin publicar

- Ajustes de herramienta: clic derecho en una herramienta para elegir su tamaño exacto con un deslizador. Cada herramienta recuerda el suyo; el botón de grosor o [ ] vuelven a fino, medio y grueso.
- Texto (T): clic para escribir; Enter guarda y ⌘/Ctrl+Enter pasa a otra línea. Clic en un texto para editarlo, y deshacer devuelve la versión anterior. Esc o Deshacer cancelan lo que escribes, y el color y el tamaño que elijas mientras escribes se aplican al texto.
- Números: cada clic pone el siguiente (1, 2, 3…) con el color y el tamaño elegidos. La cuenta sigue entre pantallas, deshacer devuelve el número y borrar todo vuelve a 1.
- Formas: al elegirla se despliegan flecha, rectángulo, elipse y línea, cada una a un clic.
- Recolorear (C): toca o arrastra sobre un trazo, una forma o un número para darle el color elegido.
- Paleta editable: doble clic o clic derecho en un color para cambiarlo; queda guardado. ⋯ → Restablecer colores.
- Otro color: la muestra arcoíris abre un panel para usar cualquier color.
- Esc cierra primero el panel de color o cancela el texto que escribes, y luego sale del modo dibujo.
- Windows: el ícono de la bandeja ahora es a color y se ve sobre la barra de tareas oscura.

## 0.1.0

Primera versión.

- Barra compacta acoplable a cualquier borde, vertical u horizontal, contraíble.
- Lápiz con presión, resaltador, puntero láser, flecha, rectángulo, elipse, línea y borrador por trazo.
- Un lienzo por monitor con deshacer y rehacer entre pantallas.
- macOS: encima de la barra de menús, el Dock y apps en pantalla completa; el foco vuelve a tu app al soltar.
- Atajo global ⌃⌥D / Ctrl+Alt+D e icono en la barra de menús o bandeja del sistema.
